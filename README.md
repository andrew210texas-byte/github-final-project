# github-final-project

## Simple Interest Calculator

This project contains a Bash script that calculates simple interest based on user-provided principal, rate of interest, and time period.

### Formula

Simple Interest = (Principal × Rate × Time) / 100

### Project Purpose

The Simple Interest Calculator is an open source project designed to demonstrate basic scripting, Git, and GitHub workflows.

### Inputs

The calculator uses:

- Principal amount
- Rate of interest
- Time period
